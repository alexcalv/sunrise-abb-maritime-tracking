# Information about the branch  
This branch contains evaluation scripts and experiments that are unrelated to the main pipeline.  

These scripts were used to evaluate YOLO-based models (YOLOv8N, YOLOv26S, YOLOv8M) across multiple metrics such as MOTA, IDF1, HOTA, Precision, and Recall.  

This code is kept here for reference, reproducibility, and experimental analysis purposes only. It is not intended to be merged into the main pipeline.

The trained models themselves are on Teams because of their size.
